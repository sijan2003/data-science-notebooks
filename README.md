# Data Science Notebooks

A collection of Python data-science notebooks documenting my learning and practice across data analysis, visualization, and machine learning.

## Contents

- **NumPy & Pandas** — array operations, data wrangling, and exploratory analysis
- **Data Visualization** — charts and plots with Matplotlib and Seaborn
- **Data Cleaning & Validation** — handling missing values, type conversion, and validation
- **Projects**
  - NYC Taxi & Limousine Commission (TLC) data analysis
  - TikTok data analysis
  - Waze project analysis
  - Sentiment analysis
- **Python practice** — small games and exercises (Hangman, Minesweeper, Slot Machine, Crisscross)

## Tech Stack

Python · Jupyter Notebook · NumPy · Pandas · Matplotlib · Seaborn · Scikit-learn

## Getting Started

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
jupyter notebook
```

Then open any `.ipynb` file in Jupyter.
